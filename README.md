# ねこねこ摩訶楼

猫のミケロがキャンディ色の不条理なダンジョンを進む、ブラウザ向けターン制ローグゲームです。

古典的なローグライクの「一歩動くと世界も一歩動く」構造を、ポップでファンシーな見た目に置き換えた小さな実験作です。

## Play

`index.html` をブラウザで直接開くか、このフォルダでローカルHTTPサーバーを起動してください。

```powershell
python -m http.server 4173
```

ブラウザで以下を開きます。

```text
http://localhost:4173
```

## Features

- ランダム生成される部屋と通路
- ターン制移動と近接戦闘
- 視界探索
- 全10階のダンジョン
- 経験値とレベルアップ
- 武器・防具の強化
- 魚による回復
- BGM音量設定とローカル音源差し替え

## Controls

- 矢印キー / WASD: 移動、隣接する敵を攻撃
- Q: 魚を食べて4 HP回復
- .: 1ターン待機
- 画面右の方向ボタン: タッチ操作用移動

鍵を拾って動く階段へ向かい、全10階を踏破するとクリアです。プレイ中または結果画面からタイトルへ戻れます。

## BGM

画面右上の `BGM` ボタンから音量を変更できます。標準ではWeb Audio APIで生成する内蔵BGMを再生します。

手元の MP3 / WAV / OGG などを選ぶと、その曲へ差し替えてブラウザ内でループ再生します。選択した音源はリポジトリやサーバーには保存されません。第三者の音楽ファイルを公開リポジトリに追加する場合は、必ず配布可能な権利を確認してください。
