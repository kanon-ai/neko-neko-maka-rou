# ねこねこ摩訶楼

猫のミケロが不条理なキャンディ色のダンジョンを進む、ブラウザ向けターン制ローグゲームです。

## 起動

`index.html` をブラウザで開くか、このフォルダでローカルHTTPサーバーを起動してください。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 操作

- 矢印キー / WASD: 移動・隣接する敵を攻撃
- Q: 魚を食べて4 HP回復
- .: 1ターン待機
- 画面右の方向ボタンでも操作可能

## BGM

画面右上の `BGM` ボタンから音量を変更できます。標準では内蔵の「まかふしぎワルツ」が再生されます。

手元の MP3 / WAV / OGG などを選ぶと、その曲へ差し替えてループ再生します。ブラウザの仕様上、ページを再読み込みした後は曲を選び直してください。音量設定は保存されます。

鍵を拾って動く階段へ向かい、全5階を踏破するとクリアです。
